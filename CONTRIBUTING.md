# Правила работы в команде
- `main` защищена: только через Pull Request, минимум 1 ревьюер.
- Ветки: `feat/<что>`, `fix/<что>`, `exp/<имя>-<идея>`. Коммиты: `feat: ...`, `fix: ...`, `docs: ...`, `exp: ...`.
- Не коммитим: данные, веса моделей, ноутбуки с тяжёлыми выводами (чистим `Cell > All Output > Clear`).
- Эксперименты: конфиг в `configs/`, метрики — в `reports/`. Один эксперимент = один конфиг + одна ветка/PR.
- Сид фиксируем (42), сплиты строим ТОЛЬКО через `brainmri.data.split` (по группам!).
- Перед PR: `pytest`.
